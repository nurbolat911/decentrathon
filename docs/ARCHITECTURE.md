## Поток данных [PLANNED]
```
Синтетические данные (счета, транзакции) ─► граф (networkx, в памяти)
                                               ▲
UI (React) ─► POST /investigate ─► Агент (LLM + tool use) ─► Инструменты (алгоритмы по графу)
   ▲                                   │
   └──── стрим шагов агента + гипотезы ┘
```

## Компоненты [PLANNED]
- **Генератор данных** (Python): создаёт счета и транзакции с заложенными схемами и «эталонными» ответами для проверки.
- **Граф-слой**: загрузка данных в networkx, выборка окрестности счёта.
- **Инструменты агента**: детерминированные функции — профиль счёта, транзакции счёта, циклы, дробление сумм (structuring), воронки/дроп-счета, сообщества, ранжирование вершины схемы. Каждая возвращает структурированный результат с id задействованных счетов и транзакций.
- **Агент**: цикл tool use. Модель вызывает инструменты, формирует гипотезы; гипотеза без ссылок на транзакции отбрасывается.
- **API** (FastAPI): запуск расследования, получение графа и гипотез, экспорт отчёта.
- **UI** (React + Cytoscape.js): лендинг, граф, лента шагов агента, карточки гипотез, действия «принять/отклонить», экспорт.

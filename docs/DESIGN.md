# Дизайн и UX

## Статус
Компонентов нет. Библиотека UI (Tailwind, MUI и др.) — **не решено**. Выбирать самое быстрое, что не мешает читаемости графа.

## Что известно из задачи
- Пользователь — аналитик: ему нужны плотность информации и проверяемость, а не декор.
- Главный экран — граф + панель гипотез + лента шагов агента.
- Каждая гипотеза показывает доказательства (счета/транзакции) и подсвечивает их на графе по клику.

## Принятые решения
- **Эстетика:** ориентир Linear — тёмная тема, монохромная база, высокая плотность, границы 1px, сдержанная анимация. Один акцент; цвета риска отдельные и акцентом не считаются.
- **Доступность:** WCAG 2.1 AA — контраст текста ≥ 4.5:1, границ и крупного текста ≥ 3:1, видимый фокус.
- **Голос интерфейса:** утилитарный — факты, id счетов и суммы; «подозрительно», а не «виновен».
- **Иконки:** Lucide, один набор, без эмодзи в интерфейсе.
- **Запрещено:** glassmorphism без контрастной границы, пастельные бейджи-«таблетки» для метаданных, декоративные градиенты и неоновые рамки, радужные кнопки, мультяшные пустые состояния, вложенные скроллбары, риск только цветом, декоративная анимация графа.
- **Лендинг:** кибербезопасный стиль без детективных образов. Кнопка «Начать» ведёт на экран расследования.
- **Языки:** русский и английский, русский по умолчанию.
- **Подробности:** визуальные решения в корневом `DESIGN.md` (зафиксирован 2026-11-05, при расхождении главный он), путь и страницы в `JOURNEY.md`.

## Принципы (для проверки при ревью UI)
- Риск нельзя передавать только цветом: добавлять значок или подпись.
- Граф остаётся читаемым при 50–200 узлах (фильтры, подсветка, зум).
- Состояния загрузки и ошибки агента видны (агент работает дольше обычного запроса).
- Базовая доступность: контраст текста, фокус с клавиатуры для основных действий.
- Адаптивность: приоритет — ноутбучный экран; на мобильном вёрстка не должна ломаться, но полноценная мобильная версия не нужна для MVP.

# Память проекта

Только устойчивые решения и ограничения. Не журнал задач.

## Решения
- **Продукт:** ИИ-помощник AML-аналитика банка (граф переводов, гипотезы с доказательствами, вершина схемы). Личный стартап.
- **Название:** Redstring — рабочее, можно сменить.
- **Стек:** React + Vite + TypeScript + Cytoscape.js; Python + FastAPI + networkx; агент — цикл tool use поверх LLM API.
- **Принцип:** детекция — детерминированные инструменты; LLM оркестрирует и объясняет. Гипотеза без ссылок на id счетов/транзакций не выдаётся.
- **Данные:** только синтетические, без реальных персональных данных. БД на старте нет, всё в памяти.
- **Дизайн:** см. `docs/DESIGN.md` (Linear, тёмная тема, WCAG AA, Lucide; лендинг в кибербезопасном стиле без детективных образов).
- **Языки:** русский и английский, русский по умолчанию; казахского пока нет.
- **Рабочий процесс:** без `git commit`/`git push` без разрешения пользователя.

## Ограничения среды
- Python 3.14.4 и Node.js v26.13.0 установлены.

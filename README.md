# Redstring (рабочее название)

ИИ-помощник для AML-аналитика банка. Агент с инструментами строит граф переводов между счетами, выдвигает гипотезы о схемах отмывания денег (с доказательствами) и находит «вершину» схемы.

> **Статус:** репозиторий на старте, кода ещё нет. Разделы «Установка» и «Запуск» заполним после создания каркаса.

## Идея
Аналитик получает алерт и вручную разбирает цепочки переводов — это занимает часы. Приложение:
1. загружает граф переводов вокруг подозрительного счёта;
2. запускает инструменты поиска схем (циклы, дробление сумм, воронки, дроп-счета);
3. строит гипотезы со ссылками на транзакции и подсвечивает подозрительный подграф;
4. ранжирует вероятных бенефициаров «на вершине»;
5. выгружает черновик отчёта о подозрительной операции.

## Планируемый стек
React + Vite + TypeScript + Cytoscape.js, Python + FastAPI + networkx, LLM API с tool use. Данные — синтетические.

## Требования к окружению
Нужны Python 3 и Node.js. На машине разработки установлены Python 3.14.4 и Node.js v26.13.0.
